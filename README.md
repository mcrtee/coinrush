# Coin Rush Online
Мультиплеерная игра на Node.js (Express + WebSocket).

    npm install
    npm start        # откройте http://localhost:3000

Переменная PORT задаёт порт. Для игры по интернету разместите на Render / Railway / Fly.io
или временно откройте через `npx cloudflared tunnel --url http://localhost:3000`.
